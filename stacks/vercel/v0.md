## What it is

v0 (v0.dev / v0.app) is Vercel's chat-driven scaffolder. Originally a UI generator (single component, single page) — by 2026 it's a full Next.js + Tailwind + shadcn + AI SDK project scaffolder, exporting working code you import into your repo. See [v0.app](https://v0.app).

## When to use

**Use it for:**

- **Initial UI scaffolds** — landing page, dashboard layout, form skeleton.
- **Component variations** — "a card component, three variants, with these props."
- **Translating Figma/screenshots into a working starting point.**
- **Iterating on copy + visual variants quickly.**
- **Bootstrapping a new app** — generate the shape, then customize.

**Don't use it for:**

- **Production data fetching** — it'll write naive client-side fetches you don't want.
- **Server Actions + Cache Components topology** — architecture is still on you; v0's output gets better but the topology decisions are human.
- **Security-sensitive forms** — validation, auth, taint — audit every output.
- **Final accessibility polish** — review every output for focus order, semantic HTML, ARIA correctness.

## 2025-2026 currency anchors

- **Expanded from UI generator to project scaffolder** (v0.app) — full Next.js + Tailwind + shadcn + AI SDK projects.
- **Output quality moves monthly** — what was bad six months ago may be good now; verify.
- **Framework support widening** beyond Next.js (verify current).

## Patterns + anti-patterns

**Pattern: v0 generate → import → wire real data → audit.** Generate scaffolding with v0; import into the codebase; replace stubbed data with Server Components / Server Actions; audit a11y + perf; ship.

**Pattern: Use v0 for visual iteration on existing components.** Paste your current component, ask for variants, take what's useful.

**Pattern: Combine with the Vercel Toolbar on Preview URLs.** "Open in v0" iterates on a deployed Preview without leaving the loop.

**Anti-pattern: Ship v0 output unaudited.** Generated code is a starting point, not a final product.

**Anti-pattern: Memorize what v0 can/can't do from six months ago.** The output quality + framework support changes monthly.

**Anti-pattern: v0 for the architecture.** It can scaffold components and pages — it's not deciding your rendering model, caching strategy, or backend topology.

## Gotchas

- **v0 generates Tailwind + shadcn idiomatically** — your codebase needs those installed for direct paste.
- **Server Component vs Client Component boundaries** — v0 often defaults to client; review and convert appropriately.
- **No knowledge of your codebase's conventions** — generated code matches v0's defaults, not your repo style. Plan for a normalization pass.
- **Output for "the latest" might lag the current Next.js minor** — verify imports against your version.
