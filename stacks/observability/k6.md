## What it is

k6 is a JavaScript-scripted load and performance testing tool by Grafana. Runs locally (CLI) or in Grafana Cloud k6 (managed). Outputs OTel-compatible metrics for correlation with [Tempo](/stacks/observability/grafana-tempo/) traces. See [grafana.com/docs/k6](https://grafana.com/docs/k6/).

## When to use

Pick k6 when:
- You need scripted load tests in CI.
- You want OTel-compatible output to your existing observability stack.
- JS scripting suits your team.

Alternatives: JMeter (legacy, GUI), Locust (Python), Gatling (Scala), Artillery (Node).

## 2025-2026 currency anchors

- **Grafana Cloud k6** managed surface for distributed load.
- **Browser testing** capability (k6 browser) for synthetic + load combined.

## Patterns

- **Scripted scenarios** — login → search → checkout flow at scale.
- **CI integration** — run baseline tests on each merge; compare to baseline.
- **OTel output** → correlate load-test latency with backend traces.

## Anti-patterns

- **Load test from inside the VPC** — misses CDN, network path effects. Run from outside.
- **No baseline + comparison** — you'll never detect regressions.

## Gotchas

- **Local k6 capacity bounded by single-machine resources** — use Grafana Cloud k6 for high-RPS tests.
- **Scripted scenarios drift from prod traffic** — review quarterly.
